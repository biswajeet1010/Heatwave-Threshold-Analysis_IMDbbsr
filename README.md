# Heatwave Threshold Analysis - IMD Bhubaneswar
## Overview

This project focuses on analyzing heatwave conditions in Bhubaneswar and surrounding regions using temperature data provided during my internship at the India Meteorological Department (IMD), Bhubaneswar.

The objective is to identify extreme temperature events using percentile-based approaches and study the spatial and temporal characteristics of heatwaves.

## Objectives

* Calculate 90th and 95th percentile temperature thresholds.
* Identify extreme heat events and heatwave days.
* Compare station observations with gridded temperature datasets.
* Analyze seasonal and annual temperature trends.
* Generate visualizations for heatwave occurrence and intensity.
* Explore spatial interpolation techniques using GIS tools.

## Dataset

The analysis uses:

* Daily maximum temperature (Tmax) data.
* Historical temperature records from recent years.
* IMD gridded datasets and station observations.

Note: Raw datasets are not included in this repository due to data-sharing restrictions.

## Methodology

1. Data cleaning and preprocessing.
2. Calculation of percentile thresholds (P90 and P95).
3. Detection of extreme temperature events.
4. Statistical analysis of heatwave frequency and duration.
5. Visualization of trends using Python.
6. Spatial analysis using GIS and interpolation methods.

## Expected Outcomes

* Heatwave threshold estimation for the study area.
* Trend analysis of extreme temperature events.
